# 기능별 현재 상태

기준일 2026-10-31. **이 표가 상태의 유일한 기준**이다. README·PLAN·DESIGN은 상태를 따로 적지 않고 여기를 참조한다.

네 칸의 뜻
- **코드**: 구현되어 있다.
- **자동 테스트**: `npm test` 또는 `bash test/ui/run.sh`가 검사한다. 가짜 서버·모의 서비스 기준이다.
- **외부 연동**: 진짜 외부 서비스(AI 제공사, Google/GitHub, 메일 서비스)로 확인했다.
- **배포 환경**: 실제 HTTPS 서버에서 해당 기능을 확인했다. 데이터 영구 보존 여부는 별도로 표시한다.

**데모와 실제 서비스는 다르다**: GitHub Pages(2026-10-25)는 브라우저 체험판이다. 실제 Node.js/WebSocket 서버는 Render Free에 배포되어 있다: https://ai-chatroom-jdjdjehejehejd-bot.onrender.com . 서버의 실제 AI 키·OAuth·메일은 설정하지 않아 AI는 데모 응답이며 로그인 연동은 꺼져 있다. Free 서비스는 영구 디스크가 없어 방·계정이 잠자기·재시작·재배포 때 사라진다.

외부 연동(AI 제공사·OAuth·메일)은 아직 검증하지 않았다. 배포 확인은 HTTPS 페이지 제공, `/healthz`, WebSocket 연결 및 데모 AI 응답에 한정한다. 실제 제공사 키를 넣을 때는 `scripts/smoke-providers.js`로 별도 확인한다. Mistral 서버 무료 풀은 API 키·명시적 모델 목록·계정 학습 옵트아웃 확인값을 모두 요구하도록 추가했지만, 현재 키가 없어 비활성 상태다.

## 다음 단계 (사람이 해야 하는 것)
1. 실제 AI가 필요할 때만 제공사 키·모델을 추가하고 `node scripts/smoke-providers.js`로 확인한다. Mistral Free mode 서버 키를 쓸 경우 제공사 계정에서 학습 옵트아웃을 먼저 확인하고, 해당 계정에 포함된 모델 ID만 명시한다. 제공사 사용료는 호스팅 무료 여부와 별개다.
2. 공개 전에 `OPERATOR_NAME`, `CONTACT_EMAIL`을 설정하고 개인정보처리방침·약관 템플릿을 실제 운영 방식에 맞게 검토한다.
3. Google/GitHub 로그인 또는 이메일 인증이 필요하면 자격증명을 설정하고 실기기에서 확인한다.
4. Render Free에서는 재시작 후 데이터가 남지 않는 것이 정상이다. 유료 전환 뒤 보존하려면 영구 디스크를 `/data`에 연결하고 `DATA_DIR=/data`로 설정한 뒤 복구를 확인한다.
5. Render Free는 유휴 15분 뒤 잠들고 다시 깨어나는 데 시간이 걸릴 수 있다. Free 사용량 한도와 초과 사용 시 계정 결제수단에 따라 서비스 정지 또는 추가 요금 가능성을 확인한다.
