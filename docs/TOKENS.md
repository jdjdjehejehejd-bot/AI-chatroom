# 토큰 절약 · 성능 메모

## 앱에 이미 들어간 것
- **오래된 발언 압축**: 프롬프트에 넣는 최근 대화 중 최신 4개를 뺀 나머지는 코드블록을 `[코드 N줄 생략]`로 접고 220자로 줄인다(`recentFor`).
- **PASS**: 정책이 "AI가 알아서 판단"일 때 부르지 않은 AI는 더할 말이 없으면 `[PASS]`만 출력한다. 출력이 짧아 비용이 작고, 전원이 연속으로 PASS하면 그 턴은 끝난다. 판단 호출도 예산을 쓴다.
- **뮤트**: 뮤트한 AI는 호출 자체를 건너뛴다(호출 비용 0).
- **DM·단체방 기억**: DM 프롬프트에는 단체방 최근 대화가, 단체방 프롬프트에는 그 AI가 받은 DM 요약이 들어간다. 다른 사람의 DM 내용은 DM 프롬프트에 넣지 않는다.

## 조사한 GitHub 프로젝트 (직접 검증하지는 않음)
대부분 **Claude Code CLI용**(개발할 때 쓰는 도구)이라 이 채팅 서버에 그대로 끼울 수는 없다. 개발 비용을 줄이는 용도로 보면 된다.
