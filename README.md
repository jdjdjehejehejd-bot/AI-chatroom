# AI-chatroom

**데모 사이트(main에 푸시할 때마다 자동 갱신)**: https://jdjdjehejehejd-bot.github.io/AI-chatroom/ — 서버 코드가 브라우저 안에서 돌아가는 체험판이라 AI 응답은 데모 문구이고, 로그인·실제 AI 호출은 동작하지 않습니다. — AI 채팅방

사람과 여러 AI가 한 방에서 대화하고, 게임·토론·공동 작업을 하는 채팅방 프로토타입.
- 제품 방향과 검증 계획: [PLAN.md](PLAN.md)
- 시스템 설계(아키텍처, 데이터 모델, 프로토콜, 오케스트레이션, 권한, 보안, 비용, 로드맵): [docs/DESIGN.md](docs/DESIGN.md)
- 화면 설계: Claude 디자인 캔버스 "AI 채팅방 UI 설계"

## 실행

```bash
npm install
npm start          # http://localhost:3000
```

브라우저 탭을 두 개 열어 같은 초대 링크(`?room=코드`)로 들어가면 다인 대화를 시험할 수 있다.

## AI 응답 모드

| 설정 | 동작 |
|---|---|
| (환경변수 없음) | **데모 모드**: 고정 문구로 응답. 비용 없음 |
| `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` / `OPENROUTER_API_KEY` + `AI_MODEL` | 서버 기본 AI가 해당 제공사를 호출 (순서대로 우선) |

**AI마다 다른 회사 모델을 쓰려면** 화면의 "AI 초대"에서 제공사(Anthropic/OpenAI/OpenRouter), 모델 이름, (선택) 개인 API 키를 지정한다. 개인 키가 없으면 서버 환경변수 키를 쓴다. 키는 서버 메모리에만 보관되고 다른 참가자에게 보이지 않지만, 서버를 거치므로 **HTTPS로 배포한 신뢰할 수 있는 서버에서만 입력**해야 한다.

제공사 주소 변경(테스트용): `ANTHROPIC_BASE_URL`, `OPENAI_BASE_URL`, `OPENROUTER_BASE_URL`

**무료 모델 (키 없이 쓰기)**: 서버 운영자가 무료 티어 키를 환경변수로 넣어 두면, 참가자는 "AI 제공사"에서 "무료 모델"을 골라 키 없이 AI를 초대할 수 있다. `default`도 유료 키가 없으면 무료 풀로 연결된다. 여러 백엔드를 돌려 쓰고, 한 곳이 429/오류를 내면 1분(인증·모델 오류는 10분) 쉬고 다음으로 넘어간다.

| 환경변수 | 설명 |
|---|---|
| `OPENROUTER_API_KEY` | OpenRouter `:free` 모델. 기본 `qwen/qwen3.8-27b:free`, `nvidia/nemotron-3-super-120b-a12b:free`, `google/gemma-4-31b-it:free`. `FREE_OPENROUTER_MODELS`로 교체 |
| `GROQ_API_KEY` | Groq. 기본 `openai/gpt-oss-120b`, `qwen/qwen3.8-27b`, `openai/gpt-oss-20b`. `FREE_GROQ_MODELS`로 교체 |
| `FREE_EXTRA_BACKENDS` | 운영자가 OpenAI 호환 백엔드를 더 추가하는 JSON. 예: `[{"id":"ovh","base":"https://.../v1","models":["gpt-oss-120b"],"cap":100}]`, 키가 있으면 `"key"` 추가. http(s) 주소만 허용, 사용자는 못 바꿈 |
| `FREE_CAP_OPENROUTER` / `FREE_CAP_GROQ` | 서버 전체 하루 호출 상한(기본 45 / 900, UTC 기준 초기화) |
| `FREE_ROOM_CAP` | 방당 무료 호출 상한(기본 20) |

**개인 키 전용 제공사**: Anthropic, OpenAI, OpenRouter, Groq는 서버 키 또는 개인 키, **NVIDIA NIM은 개인 키만** 쓴다. NVIDIA API 체험 약관(2026-10 확인)은 내부 테스트·평가 용도로만 쓰고 제3자에게 제공하지 못하게 해서, 서버 키로 다른 사람에게 대신 호출해 주는 구성에는 넣지 않았다.

**한도 참고(2026-10, 공식 문서 또는 제3자 정리 기준이라 운영 전 재확인)**: OpenRouter `:free` 분당 20회, 하루 50회(크레딧 10달러 이상 구매 시 1000회). Groq 무료 플랜 모델당 분당 30회, 하루 1000회, 하루 20만 토큰. 모델 이름과 한도는 제공사가 자주 바꾼다.

**에셋 형식** (화면의 에셋 탭에 같은 설명이 있다, 파일 12KB 이하):

```json
{
  "format": "aichat-asset/1",
  "name": "추리 게임",
  "description": "한 줄 설명(선택)",
  "policy": "free",
  "maxStreak": 4,
  "rules": "AI 프롬프트에 들어가는 방 규칙(600자 이내, 선택)",
  "ais": [{ "name": "진행자", "persona": "게임 진행자. 규칙을 정리한다." }],
  "doc": "시작 문서(선택)"
}
```

`name`, `ais`만 필수. AI는 최대 6명, 이름은 공백·@ 없이 12자 이내, 역할 200자 이내. 서버가 같은 규칙으로 다시 검증하고, 방을 만들 때(새 방만) 또는 에셋 탭에서 적용한다. 적용하면 방의 AI 구성이 교체된다. `rules`는 프롬프트에 들어가므로 에셋을 올린 사람의 지시가 그 방 AI에 영향을 준다(방 안으로만 제한).

**방 플랜과 광고**: 수익 모델은 방 단위 사용량 제한이다. 플랜이 방의 AI 인원수, AI 호출 예산, 프롬프트에 넣는 대화량, 서버 유료 모델 사용 여부, 광고 표시를 정한다.

| | 무료 | 플러스 |
|---|---|---|
| AI 인원 | 3명 | 6명 |
| 호출 예산(최대) | 30회 기본, 50회 | 100회 기본, 300회 |
| 프롬프트 대화량 | 최근 10개 | 최근 20개 |
| 서버 유료 모델(`default`, 서버 키) | 사용 불가 (무료 풀·개인 키는 가능) | 사용 가능 |
| 광고 | AI 발언 4개마다 작은 텍스트 광고 한 줄 | 없음 |

결제는 아직 없다. `ALLOW_DEV_PLAN=1`일 때만 화면의 "플랜 전환(개발용)"으로 바꿀 수 있고, 그렇지 않으면 업그레이드 버튼은 "준비 중" 안내만 띄운다. 광고 문구는 `HOUSE_ADS`(JSON, 예: `[{"text":"문구","url":"https://..."}]`, 링크는 https만)로 바꾼다. 아직 방을 소유한 계정이 없어서 플랜은 방 단위 메모리 값이고, 결제를 붙이려면 계정(구글 로그인)과 방 저장이 먼저 필요하다.

**에셋 내려받기**: 에셋 탭의 "이 방의 에셋 보관함"에 이 방에서 올리거나 적용한 에셋이 모이고(방당 10개, 방 메모리), 각각 적용·파일 저장·삭제할 수 있다. "현재 방 구성을 파일로 저장"은 모드 방을 포함해 지금 구성을 같은 형식(.aichat.json)으로 내보내며, 그대로 다시 올릴 수 있다.

**캐스트 화면, 캐스트 카드, 귓속말, ✦ 인정**: 방 위쪽의 캐스트 바에 AI와 참가자가 카드로 나열되고(AI가 답하는 중이면 "말하는 중" 표시), 카드나 말풍선 속 아바타·이름을 누르면 AI의 캐스트 카드(이름, @핸들, 배역=역할 설명, 대사 수, 받은 ✦, 귓속말 수, 엔진, 최근 대사)가 열린다. 카드에서 **귓속말 보내기**로 AI와 1:1 비공개 대화를 할 수 있다. 귓속말은 보낸 사람에게만 전달되고 다른 참가자에게는 보이지 않으며, 브라우저에 저장된 임의 키로 대화를 식별하므로 새로고침해도 이어지고 이름이 같은 다른 사람에게는 보이지 않는다. 귓속말 한 번은 방 AI 호출 예산 1회를 쓴다. AI는 자기가 받은 귓속말(최근 몇 개)을 단체방 발언 때 알고 있어서 비밀 역할 게임이 가능하다. 말풍선을 두 번 누르면 ✦(인정)이 붙는다. 디자인은 차분한 쿨 뉴트럴 바탕에 얇은 경계선과 부드러운 그림자, 원형 아바타, 알약형 캐스트 칩, 인디고 포인트 컬러를 쓰고 다크 모드를 지원한다. 글꼴은 Inter + Noto Sans KR(Google Fonts).

**공유·키트·순서·다시 만들기**: 산출물 탭에서 산출물 또는 최근 대화 30개를 링크(`/s/<id>`)로 공유한다(무료 7일·상단 안내 배너, 플러스 30일·배너 없음, 방당 10개). 설정 탭에는 브랜드 키트(Make 모드에 반영), AI 진행 순서 편집(플러스), 방 사용량 현황이 있다. "다시 만들기"는 같은 요청을 다시 실행하며 플러스는 이전 실행의 호출 예산을 돌려받는다(방당 5회). 공유 링크는 서버 메모리라 재시작하면 사라진다.

**모드 (Code / Brainstorm / Make)**: 방을 만들 때 고르거나, 에셋 탭에서 나중에 적용한다. 역할이 정해진 AI들이 정해진 순서로 이어 받아 하나의 산출물을 만들고, 결과는 산출물 탭에 쌓인다(코드는 파일로 저장, 웹페이지는 샌드박스 미리보기).

| 모드 | 무료 플랜(AI 3명) | 플러스(AI 4명) | 산출물 |
|---|---|---|---|
| Code | 설계자 → 구현자 → 리뷰어 → 구현자 | 설계자 → 구현자 → 리뷰어 → 테스터 → 구현자 | 코드 파일 |
| Brainstorm | 발산자 → 비평가 → 정리자 | 발산자 → 비평가 → 조합가 → 정리자 | 마크다운 표 |
| Make | 기획자 → 작성자 → 편집자 | 기획자 → 작성자 → 디자이너 → 편집자 | HTML 한 파일, 보고서/PPT 개요(마크다운) |

사람이 요청을 한 번 보낼 때마다 파이프라인 전체(3~5회)가 방 호출 예산에서 빠진다. 산출물은 AI가 낸 마지막 ``` 코드블록을 서버가 가져가며, 방 메모리에만 있다(최대 12,000자). 실제 .pptx/.docx 내보내기는 아직 없다.

**검증 범위**: 가짜 API 서버로 요청 형식(경로, 헤더, 모델, 키 분리, 오류 처리)만 검증했다. 실제 제공사 서버로는 아직 호출해 보지 않았다.

기타 환경변수: `PORT`(기본 3000), `ROOM_CALL_BUDGET`(방당 AI 호출 예산, 기본 30), `ROOM_CALL_BUDGET_MAX`(상한, 기본 100), `DEMO_DELAY_MS`(데모 응답 지연, 기본 700)

## 주요 기능

- 방 만들기/초대 링크, 이름 중복 처리, 접속자 목록
- AI 참가자 초대/내보내기 (이름 + 역할 설명)
- **모드**: Code, Brainstorm, Make. 역할 파이프라인과 산출물 탭
- **에셋**: 방 구성(AI 목록, 발언 방식, 연속 발언 한도, 시작 문서, 방 규칙 문구)을 JSON 파일로 올려 한 번에 적용. 게임·토론·협업 같은 기본 템플릿은 두지 않고, 사용자가 에셋으로 만든다
- 발언 정책 3종, AI 연속 발언 한도, 방별 호출 예산
- 공유 문서 (AI가 `[문서]`로 시작하는 줄을 쓰면 자동 기록)
- 개인 키 제공사: Groq, OpenRouter, Google Gemini, Mistral, NVIDIA NIM, Anthropic, OpenAI. Google·Mistral·NVIDIA는 본인 키만(약관상 운영자 키로 남의 대화를 보내지 않음)

## 로그인 · 계정 · GitHub 연동 (모두 선택)

입장 화면에 설정된 로그인 방식만 나타난다. 로그인 없이도 쓸 수 있다. 계정 ID는 방식별 접두어(`google:`, `github:`, `email:`)로 구분하며, 같은 사람이 방식을 바꾸면 다른 계정으로 취급된다(자동 병합 없음).

| 방식 | 켜는 환경변수 |
|---|---|
| Google | `GOOGLE_CLIENT_ID` (웹 OAuth 클라이언트 ID) |
| GitHub | `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` (GitHub OAuth App, 콜백 URL `<PUBLIC_URL>/auth/github/callback`) |
| 이메일 코드 | `RESEND_API_KEY` + `MAIL_FROM` (Resend 사용). 개발용으로 `EMAIL_DEV_LOG=1`이면 코드를 서버 콘솔에 출력 |
| 공통 | `SESSION_SECRET`(고정값 필수), `PUBLIC_URL`(예: `https://example.com`), HTTPS 뒤에서는 `COOKIE_SECURE=1` |

- **Google**: ID 토큰(JWT, RS256)을 서버가 Google 공개키(JWKS)로 서명·발급자·audience·만료까지 검증한다.
- **GitHub**: 표준 OAuth 웹 흐름(state 쿠키로 CSRF 방지, 복귀 경로는 같은 사이트 경로만 허용).
- **이메일**: 6자리 코드를 보내고 10분 안에 입력. 코드는 해시로만 보관, 1회용, 5번 틀리면 폐기, 주소당 10분에 3회까지 발송.
- **로그인 필수**: 위 로그인 방식이 하나라도 설정되어 있으면 로그인해야 방을 만들거나 입장할 수 있다(서버가 입장 요청을 거부하므로 화면 우회 불가). 로그인 방식이 하나도 없으면 막지 않는다. 끄려면 `REQUIRE_LOGIN=0`. 공유 링크(`/s/…`)는 로그인 없이 볼 수 있다.
- **세션**: 서명된 HttpOnly 쿠키(30일). 비밀번호는 저장하지 않는다.
- **계정에 GitHub 연동**: 로그인한 상태에서 "GitHub 연결"을 누르면 `gist` 권한만 요청한다(최소 권한). 토큰은 서버가 AES-GCM으로 암호화한 HttpOnly 쿠키에만 두고 브라우저 스크립트에는 노출하지 않으며, 연결은 그 계정에만 묶인다. 연결하면 "산출물/대화를 비공개 Gist로" 내보낼 수 있다. 연결 해제 버튼이 있다.
- **방장**: 로그인한 사람이 만든 방은 방장 전용 설정(AI 추가·삭제, 설정, 모드, 에셋, 공유, 뮤트, Gist 내보내기)이 방장에게만 열린다. 귓속말 키는 계정에서 파생되어 기기를 바꿔도 이어진다.
- **Google Play**: Google은 앱 내 WebView 로그인을 막으므로 WebView 래핑 대신 PWA + Trusted Web Activity를 권장한다. 같은 이유로 GitHub OAuth도 외부 브라우저(Custom Tab) 흐름이어야 한다.
- 실제 Google·GitHub·메일 서버로는 아직 검증하지 못했다. 모의 서버로만 테스트했다(`GOOGLE_JWKS_URL`, `GITHUB_AUTH_URL`, `GITHUB_TOKEN_URL`, `GITHUB_API_URL`, `RESEND_URL`로 대상 변경 가능).

## AI 자율 발언 · 뮤트 · AI끼리 DM · 내장 도구

- **자율 발언**: 방 정책을 "AI가 알아서 판단해 말하기"로 두면 @멘션하지 않아도 AI가 대화를 보고 말할지 `[PASS]`할지 정한다. @멘션된 AI는 항상 답하고, 뮤트한 AI는 호출되지 않는다(멘션해도 안내만 나온다). 판단 호출도 예산을 쓴다.
- **단톡 + DM 기억**: 단체방 프롬프트에는 그 AI가 받은 DM 요약이, DM 프롬프트에는 단체방 최근 대화가 들어간다.
- **AI끼리 DM**: AI가 응답에 `[DM @이름] 내용`을 쓰면 상대 AI에게만 전달된다(공개 채팅에는 안 보임). 받은 AI는 다음 차례에 답할 수 있고, 사람은 귓속말 함의 "엿보기"에서 읽을 수 있다(읽기 전용).
- **내장 도구** (정보 패널 "도구" 탭, 브라우저 안에서만 동작): JSON 정리·검증, 정규식 테스트, Base64·URL 인코딩, 색상 대비·팔레트, 글자수·토큰 추정, 창작 카드. 결과를 채팅에 붙일 수 있다.
- 토큰 절약 메모와 조사한 GitHub 프로젝트: `docs/TOKENS.md`


## 저장 · 계정 플랜 · 일일 크레딧 · 방 기억 · 에셋 마켓

- **저장**: `DATA_DIR`를 지정하면 방(대화, 문서, 산출물, 설정, 귓속말, AI끼리 DM)과 계정, 마켓이 파일로 저장되고 재시작 뒤 복원된다. 개인 API 키는 저장하지 않으며, 복원된 방에서는 키를 다시 입력하라는 안내가 나온다. 보관 기간은 무료 7일/플러스 365일(`ROOM_KEEP_DAYS_FREE`, `ROOM_KEEP_DAYS_PLUS`), 마지막 활동 기준이다. 저장소는 `store.js`의 `read/write/remove/list` 네 함수뿐이라 Redis나 DB로 바꾸기 쉽다. **Render 무료 플랜 등 디스크가 없는 환경에서는 재시작 때 사라진다**(영구 디스크가 필요하다).
- **내 계정의 방**: 로그인하면 다른 기기에서도 내가 들어갔던 방이 사이드바에 나타난다(`/api/myrooms`).
- **계정 플랜**: 방 플랜은 방장 계정의 플랜을 따른다. 결제 연동 전이므로 운영자가 `POST /admin/plan`(헤더 `Authorization: Bearer $ADMIN_TOKEN`, 본문 `{"email":"…" 또는 "sub":"…","plan":"plus","days":30}`)으로 부여한다. 결제(Play Billing 등)는 영수증을 검증한 뒤 이 로직을 호출하도록 붙이면 된다. `ADMIN_TOKEN`이 없으면 비활성.
- **일일 크레딧**: 로그인 계정마다 하루 AI 호출 한도(무료 `DAILY_FREE_CALLS`=60, 플러스 `DAILY_PLUS_CALLS`=400)를 방 예산과 별개로 건다. 요청한 사람의 크레딧이 깎이고, 한국 시간 자정에 초기화된다. DM도 포함.
- **방 기억 (플러스)**: 새 대화가 `MEMORY_EVERY`(16)개 쌓이면 AI가 요약해 "방 기억"으로 갱신하고(호출 1회 소모) 모든 AI 프롬프트에 넣는다. 무료는 직접 적어 두는 수동 기억만 쓸 수 있다.
- **에셋 마켓**: 방장이 방 구성(AI·규칙·시작 문서, 대화·키 제외)을 게시하면 다른 사람이 인기/최신순으로 찾아 설치한다. 좋아요, 신고(3건이면 숨김), 설치 수(계정당 1회), 오늘의 에셋(상위권에서 날짜별 선정), 플러스 전용 게시(설치도 플러스만). 무료 1개/플러스 10개까지 게시. 게시 전에 다른 AI의 지시를 덮어쓰려는 문구와 키·비밀번호 요구 문구를 걸러낸다(간단한 패턴 검사이며 완전하지 않으므로 신고 기능이 함께 있다).

## 출시 전 안전·개인정보 (신고·차단·삭제·보관)

> ⚠️ `/privacy`, `/terms`는 **일반적인 템플릿**이며 법률 자문이 아닙니다. 출시 전에 `OPERATOR_NAME`(운영자명), `CONTACT_EMAIL`(문의·개인정보 담당)을 반드시 설정하고, 실제 처리 방식에 맞는지 전문가 검토를 받으세요. (설정하지 않으면 페이지에 "운영자 정보 미설정" 문구가 보입니다.)

- **이용 동의**: 입장 화면에서 약관·개인정보처리방침 동의(만 14세 이상) 체크가 필요하다. 로그인 계정은 동의 시각·약관 버전을 기록하고, 서버는 동의 없는 입장을 `CONSENT_REQUIRED`로 거절한다.
- **신고**: 모든 메시지(사람·AI)의 ⋯ → 신고(스팸/욕설/성적/폭력/불법/개인정보/기타). 신고한 메시지는 내 화면에서 숨겨지고, 내용·작성자·방이 `reports`에 180일 저장된다. 운영자는 `GET /admin/reports?status=open|all`, `POST /admin/reports/resolve {id,status}`(헤더 `Authorization: Bearer $ADMIN_TOKEN`)로 확인·처리한다. 같은 사람이 같은 메시지를 두 번 신고해도 1건.
- **차단**: ⋯ → 차단. 차단한 사람의 메시지는 나에게만 숨겨진다(실시간·재입장 기록 모두). 로그인 계정은 계정에 저장, 비로그인은 접속 동안만. 설정 탭에서 해제.
- **강퇴**: 로그인한 방장이 만든 방에서 ⋯ → 강퇴. 계정(또는 이름)이 방 차단 목록에 올라 재입장이 막히고 재시작 뒤에도 유지된다.
- **계정·데이터 삭제**: `/delete-account`(앱 설정 → 계정에서도 링크). 로그인 후 '삭제' 입력 → `POST /auth/delete`. 내가 만든 방은 파일까지 삭제(접속자 즉시 퇴장), 다른 방의 내 메시지는 "[삭제된 메시지]"로 익명화, 내 귓속말·마켓 게시물·좋아요·계정 기록 삭제, 이후 옛 세션 쿠키는 무효. Play 스토어의 "계정 삭제 URL"에는 `PUBLIC_URL/delete-account`를 넣으면 된다.
- **내 데이터 내려받기**: `GET /api/export` (설정 → 계정).
- **영구 저장**: `DATA_DIR`(원자적 쓰기, 손상된 JSON은 `.corrupt-<시각>`으로 격리 후 계속 기동), 종료 신호 때 즉시 flush, 3초 디바운스. `Dockerfile`+`render.yaml`은 `/data` 영구 디스크를 마운트한다. `scripts/backup.sh`를 cron으로 돌리고 `KEEP`(기본 14일)을 방침에 적은 보관 주기와 맞춘다. `/healthz`는 헬스체크용.
- **Play 정책 체크**: ① 앱 안 신고·차단(UGC) ✔ ② 개인정보처리방침 URL `/privacy` ✔ ③ 계정 삭제 URL `/delete-account` ✔ ④ AI 생성물 신고 ✔ — 데이터 보안 양식(Data safety)은 방침 내용과 일치하게 직접 작성해야 한다.

## 완성도 기능 (앱처럼 쓰기)
- **PWA·설치**: 매니페스트·서비스워커(앱 셸만 캐시, 대화·API는 캐시 안 함)·아이콘. 출시 절차는 `docs/PLAY.md`.
- **자동 재접속**: 네트워크가 끊기거나 서버가 재시작되면 "다시 연결하는 중…" 표시 후 지수 백오프로 재접속, 방 상태를 복원한다.
- **내 메시지 삭제**: ⋯ → 삭제(방장은 모든 사람 메시지 삭제 가능). 모든 참가자 화면과 저장본에서 사라진다.
- **보안 헤더**: CSP(프레임 금지 포함), nosniff, Referrer-Policy, Permissions-Policy, HTTPS에서 HSTS. IP당 동시 접속 제한(`MAX_WS_PER_IP`).
- **운영자 화면** `/admin`: 신고 확인·처리.
- 탭이 백그라운드일 때 제목에 새 메시지 수 `(n)` 표시.

## 다국어 (한국어 · English · 日本語 · 简体中文 · Español)
- **기본 언어는 브라우저 언어**입니다. 우선순위: `?lang=xx` → 사용자가 고른 값(localStorage) → `navigator.languages` → 영어. 지원하지 않는 언어(예: 프랑스어)는 영어로 보입니다. 푸터와 설정의 🌐 선택기로 바꿀 수 있고, 선택은 기억됩니다.
- **번역 원본은 `i18n/strings.txt`** 한 파일입니다. 한 줄이 `한국어 || English || 日本語 || 简体中文 || Español`이고, 한국어 문장이 곧 키입니다. `{name}` 같은 자리표시자는 모든 언어에서 같아야 하고, 줄바꿈은 `\n`, 주석은 `# `(공백 포함)로 시작합니다.
- 문장을 고치거나 추가한 뒤에는 `python3 scripts/build-i18n.py`로 `public/i18n.js`를 다시 만들어 커밋합니다. 열 수·자리표시자·중복 키를 검사해서 틀리면 실패합니다. 새 언어는 `i18n/engine.js`의 `LANGS`/`IDX`와 `strings.txt` 열을 추가하세요.
- 화면 문구는 `_t("한국어 문장", {값})`, 서버가 보내는 한국어 문장(오류·시스템 메시지)은 클라이언트에서 `_tx()`가 패턴으로 번역합니다. 서버 문구를 바꾸면 같은 문장을 `strings.txt`에도 맞춰야 합니다.
- 서버 쪽: 이메일 인증 메일은 요청한 언어로 발송, AI 프롬프트는 대화 언어를 따라가며, 이용약관·개인정보처리방침은 `?lang=`/Accept-Language에 따라 한국어·영어 전문을 보여주고(일본어·중국어·스페인어는 영어 전문 + 번역된 메뉴), 계정 삭제 안내는 5개 언어로 제공합니다.
- **알려둔 한계**: 번역은 제가 작성한 기계 번역 수준이라 전문 검수가 필요합니다. AI 역할 이름(설계자·구현자 등)과 데모 모드의 예시 응답은 한국어로 남습니다. 법적 문서는 템플릿이므로 법률 검토를 받아야 합니다.
